# Design System

## Direction

Editorial game-operations interface: GitHub's precision with the calm tactile quality of a premium Apple utility app.

## Tokens

- Ink: `#0A0D14`
- Panel: `#111722`
- Raised panel: `#171F2D`
- Line: `#263247`
- Text: `#F5F7FB`
- Muted: `#9AA8BC`
- Signal jade: `#42E6A4`
- Ember: `#FFB86B`
- Alert coral: `#FF6B7A`
- Sky: `#70B8FF`

## Type

Use Sora for interface and headings. Use IBM Plex Mono for connection addresses, telemetry values, timestamps, and labels.

## Motion

Use 160–280ms ease-out transitions, quiet status pulse, telemetry crossfades, and loading shimmer only when waiting. Avoid bounce and elastic easing. Remove decorative motion under `prefers-reduced-motion`.

## Composition

Use a vertical operations rail: identity header, prominent selected-realm health block, then a staggered stream of telemetry panels. Avoid generic marketing grids and nested glass cards. Use thin signal grids, oversized status numerals, and a realm switcher with a clear active state.
